Point Of Sale A4 Size Receipt

Print professional A4-sized Point of Sale receipts directly from Odoo POS. This module transforms the standard POS ticket into a clean invoice-style A4 document with support for QR Codes, TLV Base64 (KSA), Arabic labels, and offline POS mode.
The standard Odoo POS receipt is optimized for thermal printers. However, many businesses need a printable A4 receipt that looks similar to an invoice.

✔ Professional A4 Invoice-Style Receipt

Convert the default POS receipt into a clean and professional A4 document.

✔ Works in Offline POS Mode

Generate and print A4 receipts even when the POS operates offline.
