ZATCA Phase 2 E-Invoicing Integration

Easily comply with Saudi Arabia's ZATCA (Zakat, Tax and Customs Authority) Phase 2 e-invoicing (FATOORAH) regulations with our seamless ZATCA integration module for Odoo. This app enables businesses in KSA to generate, validate, and automatically send VAT-compliant e-invoices directly from Odoo while meeting all ZATCA Phase 2 clearance and reporting requirements.

APPS => Zatca Integration Phase 2 => Activate
Settings => Invoicing => Zatca E-Invoicing Settings

Here you can set API Mode of the Zatca.

Settings => Invoicing => Fiscal Localization

User must have Saudi Arabia Fiscal Localization package.

Settings => Users & Companies => Company => Open Company

Here you can set Zatca details for the company.

Onboarding the Journals

On the Zatca tab of the Company, you can onboard the journal.
Clicking on the Onboard Journal button on the list of Sales Journal will open a pop-up for the OTP.

The user can receive an OTP on the phone number which is configured on the company's general information.
After entering OTP and clicking on the Request button, the journal will be onboarded.

See, Journal will be onboarded successfully.
The user also can Re-Onboard the Journal or Renew the Production CSID.

See, the onboarded journal details for ZATCA by clicking on the Journal

For submitting the Invoice to ZATCA portal, user also need to have some details of the customer

Creating a creating and confirming the invoice, system will auto Submit to the ZATCA Portal.
