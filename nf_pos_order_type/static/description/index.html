Pos Order Type

The POS Order Type module for Odoo enhances point-of-sale operations by allowing businesses to define and categorize different types of orders directly within the POS interface. With this module, store managers can create distinct order types such as dine-in, takeaway, home delivery, or instant delivery, enabling staff to quickly select the appropriate type during checkout. This categorization helps streamline workflow, improves order accuracy, and ensures that each order follows the correct processing path, reducing errors and boosting overall efficiency in busy retail or restaurant environments.

Additionally, the module provides advanced reporting and analytics by segregating orders based on type, allowing management to gain insights into sales trends, delivery performance, and customer preferences. By integrating seamlessly with Odoo’s POS system, it supports multi-store setups and ensures that pricing, promotions, and taxes can be applied correctly for each order type. This makes it an ideal solution for restaurants, retail outlets, and delivery-centric businesses looking to optimize operations while maintaining high levels of service quality.

Install Module Pos Order Type

Go to Point Of Sale

Go to Configuration Select "Pos Order Types"

Create New Pos Order Types

Create and save a new POS order type for dining.

Create and save a new POS order type for Take Away.

Create and save a new POS order type for Home Delivery with Delivery enabled.

Go to Back

Go to Configuration Go to Settings

Go to POS Order Types and select the order type you want.

Go to Point Of Sale.

Open the Register

Click on the Order Type button.

Select the ‘Order Type’ button and then choose ‘Dining’.

You can see that the selected order type is displayed on the ‘Order Type’ button. Click the ‘Dining’ button again if needed.

Now click on the ‘Home Delivery’ order type. You will see the warning message: ‘No customer selected…’.

Now click on the ‘Customer’ button.

Now select the customer who does not have an address (‘Any Street Line’).

You can see that the desired customer is selected. Click the ‘Dining’ button.

Now click on ‘Home Delivery,’ and you will see the warning message: ‘Customer address is missing…’.

Click the currently selected ‘Customer’ button.

Now select the customer who has an address.

You can see that the desired customer is selected. Click the ‘Dining’ button.

Click the ‘Home Delivery’ button.

You can see that the ‘Home Delivery’ type is selected, along with the chosen delivery order type. Then, click the ‘Payment’ button to make the payment.

Now click the ‘Validate’ button to validate the payment.

In the receipt, you can see that your order type is displayed.
