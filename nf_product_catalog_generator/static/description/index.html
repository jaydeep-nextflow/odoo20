Product Catalog Generator

Product Catalog Generator is a powerful Odoo module designed to create, customize, and export professional product catalogs in multiple formats and styles. It allows users to generate dynamic catalogs with products, categories, pricing options, and layouts, and export them as PDF or Excel reports or share via email.

Platform Support

Community Enterprise Odoo.sh

It allows businesses to generate visually rich product catalogs directly from Odoo using a wizard interface. Users can select products or categories, apply custom styles, configure pricing rules, and export catalogs in PDF or Excel formats or share them via email. This module is ideal for sales teams, wholesalers, and retailers who need a flexible and automated product catalog system inside Odoo.

Product Catalog Management
  • The module allows users to generate and manage product catalogs directly from Odoo. A dedicated Product Catalog menu provides easy access to create, view, and manage generated catalogs.
  • Main Menu Structure:
    • Product Catalog
      • Product Catalog
      • Generate Product Catalog
  • Users can create catalogs based on products or categories and store generated catalogs for future printing or sharing.
Email Catalog Sharing
  • The module supports sending catalogs directly via email.
  • Users can:
    • Generate catalog email
    • Attach the catalog report and excel file
    • Send it to customers or partners
  • This makes sharing product catalogs quick and efficient.
Catalog Generation Wizard
  • A powerful wizard form helps users configure catalog details before generating reports.
Product Image Settings
  • The wizard form includes the following fields to configure the product catalog:
  • Users can control how product images appear inside the catalog.
  • Options include: (wizard form)
    • Enable/Disable product image
    • Image Height (in pixels)
    • Image Width (in pixels)
  • This allows businesses to maintain consistent catalog layouts.
Products Pricing
  • The wizard form includes the following fields to configure the product catalog:
  • The module supports advanced pricing settings.
  • Features include: (wizard form)
    • Show/Hide product price
    • Pricelist selection
    • Price decimal precision configuration
Multiple Catalog Layout Styles
  • The wizard form includes the following fields to configure the product catalog:
  • Users can choose from multiple catalog display styles depending on presentation needs.
    • Available styles:
      • Default Style
      • Box Style
      • Row Style
      • Bubble Style
      • Style 5
  • Each style provides a unique layout for printing the product catalog report.
Box Layout Customization
  • The wizard form includes the following fields to configure the product catalog:
  • When Box Style is selected, additional layout options appear.
  • Users can choose how many products appear per row:
    • 2 Boxes per Row
    • 3 Boxes per Row
    • 4 Boxes per Row
  • This helps create grid-based catalog designs suitable for print or digital use.
Page Break Control
  • The wizard form includes the following fields to configure the product catalog:
  • The module supports automatic page breaking to maintain clean catalog formatting.
  • Options include:
    • Enable/Disable page break
    • Set number of products after which a page break occurs
  • This ensures professional catalog layouts in PDF reports.
Print Options
  • Users can generate catalogs in different formats.
  • Available outputs:
    • PDF Catalog Report
  • Multiple report styles are available when printing catalogs:
    • Catalog Style 1 Report
    • Catalog Style 2 Report
    • Catalog Style 3 Report
    • Catalog Style 4 Report
    • Catalog Style 5 Report
  • Each report style follows the selected catalog layout.
User Access Control
  • Role-based access ensures secure catalog management.
  • User roles include:
    • Product Catalog User
    • Product Catalog Manager
  • This allows organizations to control who can generate, manage, or modify catalogs.
