Sale Boxes On Website

Transform your Odoo eCommerce store by allowing customers to purchase products in predefined box quantities. This module introduces a simple and powerful boxed sales workflow where products can be sold based on box sizes and predefined quantities, ensuring accurate ordering and improved customer experience.
The module allows administrators to define box products and associated quantities directly from the product configuration. When customers add products to their cart from the website, optional box selections are displayed automatically, enabling quick selection of predefined box quantities. The system then calculates the total quantity and pricing automatically based on the selected box.

What is the purpose of this module? +

This module allows customers to purchase products in predefined box quantities through your Odoo website, making bulk and packaged product sales easier and more accurate.

Can I define different box sizes for different products? +

Yes, You can configure unique box sizes and quantities for each product according to your business requirements.

How are box sizes configured? +

Box sizes are configured using Odoo's Optional Products functionality. You can assign box options and define their corresponding quantities from the product form.

Where are box options displayed to customers? +

Box options are displayed on the website during the Add to Cart process, allowing customers to select their preferred box size before adding the product to the cart.

Does the module automatically calculate quantities? +

Yes, The module automatically calculates the actual product quantity based on the selected box size.
