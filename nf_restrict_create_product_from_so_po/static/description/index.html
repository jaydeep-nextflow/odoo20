Restrict Create Product From SO/PO

This module prevents users from creating new products directly from Sale Orders or Purchase Orders.

It ensures that only authorized personnel (e.g., product managers) can add new products in the inventory, maintaining data consistency and avoiding accidental creation of duplicate or incomplete product records.

Restrict to create Product from So/PO

Hot Features

Restrict Product Creation

Disables the “Create” and “Create and Edit…” options on product fields in Sales Orders and Purchase Orders.

User Group-Based Control

Restriction applies to standard users.

Consistent Product Master Data

Prevents unauthorized users from creating incorrect or duplicate products during sales or purchasing processes.

Configurable Access

Admins can manage who can create products by adjusting user access rights in Settings → Users & Companies.

Seamless Integration

Works with both Sales and Purchase apps.

Restrict Product Creation from Sales Orders
  • When users create or edit a Sales Order, the Product field (on order lines) no longer allows creating a new product.
Configuration & Setup
  • No manual setup needed — works automatically upon installation.
Role-Based Access Control
  • Allows managers or admin users (configurable) to still create products from SO/PO if required.
Improves Data Integrity
  • Ensures that only approved, standardized product records are used in transactions.
Plug & Play — No Configuration Needed
  • The restriction applies immediately upon installation.
Improves Reporting Accuracy
  • Since all orders must reference valid products, sales and purchase reports remain consistent.
